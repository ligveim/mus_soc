# Underground Musicians Discovery

Одностраничное веб-приложение для поиска малоизвестных электронных музыкантов с их социальными сетями и статистикой подписчиков.

## 🎯 Что сделано

### ✅ Полностью готово
- **Расширен список артистов**: с 91 до 192 музыкантов (+106%)
- **Создан одностраничник** с современным дизайном
- **Функционал поиска** по имени артиста
- **Сортировка** по имени и количеству подписчиков
- **Адаптивный дизайн** для мобильных устройств

### 🔄 В процессе
- **Сбор социальных сетей**: 9/192 артистов (5%)
- **Сбор статистики подписчиков**: 9/192 артистов (5%)

## 📊 Статистика

- **Всего артистов**: 192
  - Оригинальных: 95
  - Найденных похожих: 97
- **С данными о соцсетях**: 9
- **Процент готовности**: ~30%

## 🎨 Особенности

### Дизайн
- Темная тема с градиентами
- Стеклянные карточки артистов (glassmorphism)
- Плавные анимации
- Адаптивная сетка

### Функционал
- **Поиск в реальном времени**
- **Три режима сортировки**:
  - По имени (А-Я)
  - По подписчикам (от малоизвестных к известным)
  - По подписчикам (от известных к малоизвестным)
- **Автоматические ссылки** на:
  - Instagram
  - Spotify
  - TikTok
  - Twitter
  - Bandcamp
  - SoundCloud

## 🚀 Запуск

```bash
# Открыть index.html в браузере
open index.html

# Или запустить локальный сервер
python3 -m http.server 8000
# Затем открыть http://localhost:8000
```
